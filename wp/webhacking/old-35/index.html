Challenge

Bypass the phone-number insert with SQL injection.

通过 SQL injection 绕过电话号码写入。

Analysis

?view_source=1 给出源码：

phone 直接拼入 VALUES 的第三个字段，外层没有引号。它的过滤规则禁止 * / = select - # ;，但允许单引号、逗号和括号，足以闭合当前元组并追加第二个元组。

GET 参数 id 最多 5 字节，且不能包含 admin（大小写不敏感），因此直接提交 id=admin 会被拒绝。通过 phone 追加的行不经过这项 id 检查。
