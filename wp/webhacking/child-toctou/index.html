Challenge

Analysis

api.php 不直接执行命令，而是先校验 Host，再用 Host 去请求同端口的 /cmd/<q>.txt，最后把该文件的内容当命令执行：

关键点是 Host 被解析两次：gethostbyname() 解析一次做校验，curl 再解析一次取内容，中间还夹着 sleep(1)。这就是 TOCTOU。

现场实测分支：

/cmd/ 目录是预置白名单（ls.txt、cat api.php.txt、cat index.php.txt），?q=cat flag.php 会返回 only "ls", "cat api.php", "cat index.php" allowed。

Solution

链条：让 Host 在校验时解析到 202.182.106.159（目标自己），在 curl 请求时解析到攻击者服务器，从而让 http://<Host>:10020/cmd/<q>.txt 返回任意命令文本，被 system() 执行。

Host 必须匹配 /^[a-z0-9-.]+$/，所以使用符合格式的 DNS rebinding 域名。草稿记录 rbndr.us 在该目标上两种 IP 顺序都返回 Something wrong；1u.ms 的 make-<ip1>-rebind-<ip2>-rr.1u.ms 可用。
