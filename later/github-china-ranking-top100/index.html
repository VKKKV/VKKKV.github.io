什么是衡量 GitHub 开发者「实力」的正确方式？Followers 最直观但容易被名气主导，Stars 能反映项目热度但单爆款可能失真，Repos 数量代表广度但质量难保证。这篇排行榜用六维加权公式（Followers (25%) + Repos (15%) + Stars (20%) + 活跃年 (15%) + 密度 (15%) + 语言激励 (10%)）试图给出一个更立体的答案。

收录标准：中国国籍 / 在中国工作 / 中文为主要语言的 GitHub 开发者。部分外籍开发者以工作地关联纳入。

多维度综合评分基于 githubrank.com (2026-06) + gitstar-ranking.com 数据。

排名公式

分量 权重 计算方法 含义
Followers 25% ln(f+1)/ln(max_f+1) × 25 社交影响力
Repos 15% ln(r+1)/ln(max_r+1) × 15 产出广度
Stars 20% ln(s+1)/ln(max_s+1) × 20 项目总 Star 数
Years 15% years_active/max_years × 15 持续参与时间
Density 15% max(ln(rpy+1)/Mrpy, ln(spy+1)/Mspy) × 15 取 max(仓库密度, Star 密度)
Language 10% 语言加权分 (0-10) 系统语言加分

密度改用 max 模式：每人自动选用自己最强的密度指标。（Mrpy = 全体开发者中 ln(rpy+1) 的最大值，Mspy = 全体开发者中 ln(spy+1) 的最大值。）

  • 多仓库开发者（felixonmars 115 repos/yr）→ 用仓库密度 rpy
  • 单爆款开发者（CyC2018 23k stars/yr）→ 用 Star 密度 spy

Top 100 开发者简介

#1 justjavac（迷渡）

天津 · Deno 贡献者 · 445 repos · 200k stars

justjavac，中文名迷渡，取自「雾失楼台，月迷津渡」。2010 年注册 GitHub，全栈工程师。他是 Deno 中文社区的核心发起人、vscode_deno 创建者。其维护的 awesome-wechat-weapp（微信小程序资源汇总）拥有 50k+ stars，是中文小程序生态最大的资源索引。他还维护了免费的编程中文书籍索引、Chrome Sniffer Plus 插件、ali-words（互联网黑话词汇表）等多个广泛使用的项目。自述「懒惰是程序员最大的美德」（出自其个人博客）

#2 ruanyf（阮一峰）

上海 · 科技博主 · 75 repos · 208k stars

阮一峰，中国技术社区最著名的独立博主之一。2003 年起撰写博客（ruanyifeng.com），2011 年注册 GitHub。其科技爱好者周刊（weekly）拥有 88k+ stars，每周五定时发布，截至 2026 年 6 月已发行 400 期，是国内影响力最大的个人科技资讯周刊。他还著有《ECMAScript 6 入门》（21k stars）、全栈工程师培训材料（20k stars）、中文技术文档写作规范（12k stars）等开源书籍/教程。GitHub 粉丝 86k+，位列全站中文个人开发者第一，但仓库偏少（75）、密度偏低（5 repos/yr），典型的内容输出型开发者。

#3 cloudwu（云风）

前网易游戏核心开发者 · 简悦科技创始人 · 139 repos · 30k stars

云风，原名不详，70 年代末出生，国内游戏开发领域的标志性人物。6 岁开始编程，中学时写出 Cview 软件，大学开发「风魂」游戏引擎，后被网易用于《大话西游》《梦幻西游》的开发。2011 年注册 GitHub，核心开源项目 skynet 是游戏行业广泛使用的网络服务框架，也是国内游戏开发的事实标准之一。著有《游戏之旅——我的编程感悟》。离开网易后创立简悦科技（后并入阿里游戏）。C 语言技术栈、21k 粉丝、15 年活跃，是典型的系统层工程型开发者。

#4 521xueweihan（削微寒）

北京 · HelloGitHub 创始人 · 165 repos · 209k stars

削微寒，HelloGitHub 创始人兼维护者。2014 年注册 GitHub，所在公司显示为「公众号：HelloGitHub」。其创办的 HelloGitHub 项目（153k stars）是中文社区最大的入门级开源项目月刊，每月 28 号发布，分享有趣、易上手的开源项目，帮助新手找到编程的乐趣。另维护 GitHub520（28k stars，解决 GitHub 访问图裂问题）和 git-tips（15k stars，Git 奇技淫巧）。Stars 总数 209k+ 为中国区个人开发者最高之一。

#5 astaxie（谢孟军）

上海 · Go 语言中国布道师 · beego 作者 · 83 repos · 55k stars

谢孟军（Asta Xie），Go 语言中国首席布道师、Go 基金会主席、Gopher China 社区创始人。2010 年注册 GitHub，是 Go 生态最早的中文贡献者之一。创建了 beego 框架（Go 语言最知名的 Web 框架之一，现托管于 beego 组织），以及 beedb（首个 Go ORM 库）。著有开源书《Go Web 编程》（43k stars），是 Go 语言中文学习的必读材料。现为积梦智能 CEO，近年转向 AI 领域，开发 DeepChat 和 Go-MCP 等项目。

#6 felixonmars（Felix Yan）

武汉 · Arch Linux 开发者 · 1704 repos · 9.6k stars

Felix Yan（颜 Felix），1991 年出生，Arch Linux 官方开发者，武汉深之度科技高级 R&D 工程师。GitHub 上 1704 个仓库，是本次排名中仓库数最多的个人开发者。其工作主要为 Arch Linux 包维护（archriscv、archlinuxcn 仓库）、Deepin 系统开发、以及各类上游贡献。他的仓库覆盖了从 DNS 配置（chnroutes）、输入法（fcitx5-pinyin-zhwiki）到系统工具（vps2arch）的广泛领域，是典型的「基础设施型」开发者：代码产出量大但单项目 Star 不高，体现了开源生态中打包/维护工作的价值。

#7 easychen（Easy）

重庆 · 独立开发者 · 方糖气球创始人 · 264 repos · 88k stars

Easy，网名 easychen，重庆独立开发者，方糖气球（ftqq.com）博主。2011 年注册 GitHub，是最早一批在国内实践独立开发的程序员。他创作的 Server 酱（消息推送服务）是国内最知名的消息推送服务之一，另维护 CookieCloud（浏览器 Cookie 端到端同步，3k stars）、Check酱（网页内容监测）等实用工具。同时还著有《精益副业》（12k stars）和《一人公司方法论》（8k stars），在程序员副业和独立开发者社区有极大影响力。

#8 amusi（Amusi / CVer）

上海 · 计算机视觉知识库 · 255 repos · 68k stars

Amusi，微信公众号「CVer」运营者，专注于计算机视觉（CV）和 AI 领域的知识整理。2016 年注册 GitHub，上海。其创建的 CVPR Papers with Code 系列（22k stars）是 CV 顶会论文与开源代码的最大中文索引库，每年更新。另维护深度学习面试宝典（8.7k stars）、AI 算法岗求职攻略（6k stars）、awesome-object-detection（7.5k stars）等资源型项目。他是 CV 中文社区最大的信息枢纽之一。
